Kierunkowskazy i klakson

Dwa projekty: układ sygnalizacji kierunku jazdy z przekaźnikiem oraz sygnał dźwiękowy klaksonu i biegu wstecznego. W każdym projekcie pracujesz na jednym programie i rozbudowujesz go fragment po fragmencie.

Zanim włączysz zasilanie

  1. Połączenia zmieniasz tylko przy odłączonym zasilaniu.
  2. Przekaźnik i inne odbiorniki mocy zasilasz z szyn modułu MB102 — nigdy z wyprowadzeń ESP32.
  3. Masa modułu zasilającego i masa ESP32 muszą być połączone.
  4. W etapach oznaczonych ⚠ kontrola podnieś rękę i poczekaj na sprawdzenie.
  5. Diodę LED zawsze łączysz przez rezystor.
  6. Moduł przekaźnika ma własną diodę zaporową — przy nim niczego nie dokładasz. Diodę 1N4007 wstawiasz tylko przy cewkach, które budujesz sam na płytce stykowej.

Zasada trzech kroków — zanim poprosisz o pomoc

  1. Sprawdź instrukcję: czy wykonałeś wszystkie punkty po kolei? Czy fragment trafił do właściwego MIEJSCA?
  2. Sprawdź zasilanie, masę i przewody — czy to znowu nie jest przerwany przewód?
  3. Porównaj swój układ ze schematem, element po elemencie.

Dopiero potem podnieś rękę.

Sprawdzenie stanowiska — przed zajęciami 0 / 0

Przelicz elementy i zaznacz te, które są na stanowisku i są sprawne. Braki oraz uszkodzenia zgłoś teraz — zanim zaczniesz cokolwiek budować. Zgłoszenie jest w twoim interesie.

01

Kierunkowskazy i światła awaryjne

Zbudujesz układ, który miga tak jak kierunkowskaz w aucie — razem z przekaźnikiem klikającym w rytm migania.

Informatyka: czasy migania, warunki, tablice Elektronika: LED, rezystory, przyciski, tranzystor Mechanika: zwora przekaźnika

Program bazowy tego projektu

W tym projekcie wgrywasz jeden program: P01_bazowy.ino. W kolejnych etapach nie dostajesz nowych plików — dopisujesz do niego fragmenty kodu z tej instrukcji. Każdy fragment ma podane miejsce, w które trafia.

Skąd to znasz z auta: przerywacz kierunkowskazu to przekaźnik — dlatego w kabinie słychać klikanie. Gdy przepali się żarówka, rytm migania przyspiesza.
▸Etap 1 Uruchomienie programu bazowego Bazowy
  1. Zmontuj obwód: wyprowadzenie ESP32 → rezystor 220 Ω → dłuższa nóżka diody żółtej; krótsza nóżka → masa.
  2. Otwórz plik P01_bazowy.ino i przeczytaj komentarze. Znajdź cztery MIEJSCA — w nich będziesz pracował przez cały projekt.
  3. Wgraj program. Dioda zacznie migać.
  4. Policz stoperem, ile razy zapali się w ciągu 30 sekund.
  5. W aucie kierunkowskaz miga 60–120 razy na minutę. Zmień czasMigania w MIEJSCU A tak, aby trafić w ten zakres, i wgraj ponownie.
Zmieniasz w kodzie: czasMigania w MIEJSCU A.
▸Etap 2 Przycisk jako manetka kierunkowskazu Bazowy
  1. Wyłącz zasilanie. Dołóż przycisk: jedna nóżka do wyprowadzenia z planszy, druga do masy.
  2. Przepisz do programu trzy poniższe fragmenty — każdy do swojego MIEJSCA.
  3. Wgraj program i sprawdź: dioda miga tylko przy wciśniętym przycisku.
  4. Zmierz multimetrem napięcie na wyprowadzeniu przycisku — zwolniony i wciśnięty.

MIEJSCE D — własne funkcje dopisz

Funkcje umieszczamy poza setup() i loop() — w MIEJSCU D.

// Funkcja zapala kolejne diody jedna po drugiej.
// Wywołujemy ją z MIEJSCA C, gdy manetka jest wciśnięta.
void falaLewa() {
  if (millis() - startFali >= opoznienieFali) {
    startFali = millis();
    if (aktualnaDioda < 4) {
      digitalWrite(pinyLewe[aktualnaDioda], HIGH);
      aktualnaDioda++;
    } else {
      for (int i = 0; i < 4; i++) digitalWrite(pinyLewe[i], LOW);
      aktualnaDioda = 0;
    }
  }
}

MIEJSCE D — własne funkcje dopisz 
// Wysyła jedną klatkę do rejestru.
// shiftOut wysyła osiem bitów jeden po drugim,
// a zatrzask sprawia, że diody zmieniają się wszystkie naraz.
void pokaz(byte wzorzec) {
  digitalWrite(pinZATRZASK, LOW);
  shiftOut(pinDANE, pinZEGAR, MSBFIRST, wzorzec);
  digitalWrite(pinZATRZASK, HIGH);
}

02

Klakson i sygnał cofania

Zbudujesz dwutonowy klakson i przerywany sygnał biegu wstecznego, a na koniec przełączysz klakson na obwód mocy z przekaźnikiem.

Informatyka: częstotliwość dźwięku, czasy przerw, tablice Elektronika: tranzystor PN2222, dioda 1N4007, przycisk Mechanika: membrana brzęczyka, zwora przekaźnika

Program bazowy tego projektu

W tym projekcie wgrywasz jeden program: P02_bazowy.ino. W kolejnych etapach nie dostajesz nowych plików — dopisujesz do niego fragmenty kodu z tej instrukcji. Każdy fragment ma podane miejsce, w które trafia.

Skąd to znasz z auta: klakson pobiera duży prąd, dlatego przycisk na kierownicy steruje tylko przekaźnikiem. Prawdziwy klakson jest zwykle dwutonowy.
▸Etap 1 Uruchomienie programu bazowego Bazowy
  1. Zmontuj obwód z brzęczykiem aktywnym i przyciskiem według schematu.
  2. Otwórz P02_bazowy.ino. Na górze są gotowe narzędzia dźwięku — nie zmieniasz ich, ale od etapu 2 będziesz z nich korzystał.
  3. Wgraj program i sprawdź działanie.
  4. Brzęczyk aktywny ma jeden, stały dźwięk — nie da się go zmienić.
Bez zmian w kodzie — sprawdzasz, że program bazowy działa.

// Wykrywamy MOMENT naciśnięcia, a nie samo trzymanie przycisku:
// stan zmienił się z wysokiego na niski.
void obsluzGlosnosc() {
  bool stan = digitalRead(pinPrzycisk);
  if (poprzedniStan == HIGH && stan == LOW) {
    dzwiekGraj(pinBrzeczyka, 2000);
    dzwiekGlosnosc(pinBrzeczyka, poziomy[wybrany]);
    delay(600);
    dzwiekGlosnosc(pinBrzeczyka, 0);
    wybrany++;
    if (wybrany > 2) wybrany = 0;
    delay(200);   // krótka zwłoka na drgania styków
  }
  poprzedniStan = stan;
}

Programowanie ESP32 — od zera

Krótko i po kolei: podłączenie płytki, ustawienia programu, z czego składa się kod, jak go wgrać i co robić, gdy pojawi się błąd.

1. Podłącz płytkę do komputera

  1. Weź kabel USB ze stanowiska i połącz płytkę z komputerem.
  2. Na płytce powinna zapalić się mała czerwona dioda — to znak, że ma zasilanie.
  3. Jeśli nic się nie świeci: spróbuj innego gniazda USB, a potem innego kabla. Część kabli USB służy tylko do ładowania i nie przesyła danych — to najczęstsza przyczyna problemu.

2. Ustaw program Arduino IDE

  1. Uruchom Arduino IDE.
  2. Menu Narzędzia → Płytka — wybierz ESP32 Dev Module.
  3. Menu Narzędzia → Port — wybierz port, który pojawił się po podłączeniu płytki (np. COM5). Jeśli nie wiesz który: odłącz kabel, sprawdź listę, podłącz ponownie — nowy port to twoja płytka.
Jeśli lista portów jest pusta, komputerowi brakuje sterownika układu USB (CH340 albo CP2102). Zgłoś to nauczycielowi — sam tego nie zainstalujesz.

3. Z czego składa się program

Każdy program dla płytki ma dwie części:

void setup() {
  // wykonuje się RAZ, zaraz po włączeniu
  // tutaj ustawiasz, co jest wejściem, a co wyjściem
}

void loop() {
  // wykonuje się W KÓŁKO, bez końca
  // tutaj dzieje się właściwe działanie układu
}

setup to przygotowanie — jak ustawienie lusterek przed jazdą. loop to sama jazda, powtarzana bez przerwy tysiące razy na sekundę.

4. Podstawy zapisu

Zapis Co robi
int pinDiody = 2; tworzy pudełko o nazwie pinDiody i wkłada do niego liczbę 2
; średnik kończy każde polecenie — jak kropka w zdaniu
// tekst komentarz — notatka dla człowieka, płytka to pomija
pinMode(2, OUTPUT); ustawia wyprowadzenie 2 jako wyjście (steruje czymś)
pinMode(4, INPUT_PULLUP); ustawia wyprowadzenie 4 jako wejście (czyta przycisk)
digitalWrite(2, HIGH); podaje napięcie na wyprowadzenie 2 — dioda zapala się
digitalWrite(2, LOW); odcina napięcie — dioda gaśnie
delay(500); czeka 500 milisekund, czyli pół sekundy
digitalRead(4) sprawdza, czy na wejściu jest napięcie

Przykład — dioda miga co pół sekundy:

int pinDiody = 2;

void setup() {
  pinMode(pinDiody, OUTPUT);
}

void loop() {
  digitalWrite(pinDiody, HIGH);   // zapal
  delay(500);                     // czekaj pół sekundy
  digitalWrite(pinDiody, LOW);    // zgaś
  delay(500);                     // czekaj pół sekundy
}

Warunek — „jeżeli":

if (digitalRead(pinPrzycisku) == LOW) {
  digitalWrite(pinDiody, HIGH);   // przycisk wciśnięty → zapal
} else {
  digitalWrite(pinDiody, LOW);    // w przeciwnym razie → zgaś
}
Uwaga na dwa znaki równości. = oznacza „wpisz wartość", a == oznacza „sprawdź, czy równa się". W warunku zawsze używasz ==.

Pętla — powtórz kilka razy:

for (int i = 0; i < 4; i++) {
  digitalWrite(pinyDiod[i], HIGH);
  delay(100);
}

To znaczy: weź kolejno diody o numerach 0, 1, 2, 3 i zapal każdą z odstępem 100 ms.

Tablica — kilka wartości pod jedną nazwą:

int pinyDiod[4] = {2, 4, 5, 18};

Kolejność w nawiasach klamrowych ma znaczenie — to ona wyznacza kolejność zapalania.

5. Wgraj program do płytki

  1. Kliknij ✓ Zweryfikuj — program zostanie sprawdzony, ale jeszcze nie wgrany.
  2. Kliknij → Wgraj. Na dole pojawi się pasek postępu i napisy o zapisie.
  3. Poczekaj na komunikat o zakończeniu. Płytka sama się zrestartuje i zacznie działać.
  4. Jeśli wgrywanie się zatrzyma: przytrzymaj na płytce przycisk BOOT, aż zacznie się zapis, a potem puść.

6. Gdy pojawi się błąd

Czerwony tekst na dole to nie awaria — to informacja, co poprawić. Czytaj zawsze pierwszą linię błędu, reszta zwykle z niej wynika. W nawiasie po nazwie pliku jest numer linii — tam zacznij szukać.

Komunikat Co znaczy Co zrobić
expected ';' before... brakuje średnika sprawdź koniec linii powyżej wskazanej
... was not declared in this scope nieznana nazwa literówka albo brak deklaracji zmiennej na górze pliku
expected '}' at end of input brakuje klamry zamykającej policz klamry — każda otwierająca musi mieć zamykającą
stray '#' in program przypadkowy znak w kodzie usuń znak z linii wskazanej w błędzie
Failed to connect to ESP32 płytka nie odpowiada sprawdź port, przytrzymaj BOOT, zmień kabel
Port not found / brak portu komputer nie widzi płytki inny kabel, inne gniazdo, zgłoś nauczycielowi
A fatal error occurred przerwane połączenie odłącz i podłącz kabel, wybierz port ponownie

7. Program się wgrał, ale układ nie działa

To już nie jest błąd programu, tylko układu. Sprawdź po kolei:

  1. Czy numer wyprowadzenia w programie zgadza się z tym, gdzie faktycznie wpiąłeś przewód?
  2. Czy dioda nie jest odwrotnie? Dłuższa nóżka do plusa.
  3. Czy masa jest wspólna dla wszystkich elementów?
  4. Czy przewody na pewno są sprawne?
  5. Czy zasilanie jest włączone i zworki ustawione prawidłowo?
Kliknij raz i wskaż plik — dalej wyniki zapisują się same co minutę.
